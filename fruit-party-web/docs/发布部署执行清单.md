# 水果派对发布部署执行清单

适用分支：`codex/iteration-one`
渲染方案：默认使用项目内置的 Three.js 程序化水果模型，不依赖外部 GLB 文件。

## 1. 本地发布前检查

在项目根目录执行：

```powershell
npm ci
npm test
npm run build
npm run verify:fruit-assets
```

当前 `verify:fruit-assets` 会列出尚未下载的可选 GLB，但默认以程序化模型发布时返回成功。只有计划启用写实 GLB 时才执行严格检查：

```powershell
$env:REQUIRE_GLTF_ASSETS='1'
npm run verify:fruit-assets
```

提交代码前确认 `.env`、数据库备份、证书和私钥没有被加入 Git。

```powershell
git status
git diff --check
```

## 2. 服务器准备

推荐 Ubuntu 22.04 或 24.04，至少 2 核 2GB 内存。安装 Node.js LTS、MySQL、Nginx、Git、PM2：

```bash
sudo apt update
sudo apt install -y nginx mysql-server git curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2
```

确认安装：

```bash
node -v
npm -v
mysql --version
nginx -v
pm2 -v
```

## 3. MySQL 初始化

进入 MySQL：

```bash
sudo mysql
```

创建数据库和应用账号，替换尖括号中的密码：

```sql
CREATE DATABASE fruit_party CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'fruit_app'@'127.0.0.1' IDENTIFIED BY '<强密码>';
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, INDEX, DROP
ON fruit_party.* TO 'fruit_app'@'127.0.0.1';
FLUSH PRIVILEGES;
```

应用账号只用于项目 API，MySQL root 只用于维护。

## 4. 获取代码与环境变量

```bash
sudo mkdir -p /srv/fruit-party
sudo chown $USER:$USER /srv/fruit-party
git clone <你的 GitHub 仓库地址> /srv/fruit-party/app
cd /srv/fruit-party/app
npm ci
npm run build
```

创建 `/srv/fruit-party/app/.env`：

```env
NODE_ENV=production
PORT=3000
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=fruit_app
MYSQL_PASSWORD=<数据库强密码>
MYSQL_DATABASE=fruit_party
MYSQL_POOL_SIZE=10
JWT_SECRET=<随机密钥>
CORS_ORIGIN=https://<你的域名>
```

生成 JWT 密钥：

```bash
openssl rand -base64 48
chmod 600 .env
```

生产环境缺少 `JWT_SECRET` 时，API 会拒绝启动。

## 5. 用 PM2 启动 API

创建 `/srv/fruit-party/app/ecosystem.config.cjs`：

```js
module.exports = {
  apps: [{
    name: 'fruit-party-api',
    script: './server/index.js',
    cwd: '/srv/fruit-party/app',
    instances: 1,
    exec_mode: 'fork',
    env: { NODE_ENV: 'production' },
    max_memory_restart: '500M',
    time: true,
  }],
}
```

启动并设置开机自启：

```bash
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

执行 `pm2 startup` 输出的 sudo 命令。检查：

```bash
pm2 status
pm2 logs fruit-party-api
curl -fsS http://127.0.0.1:3000/api/health
```

初次部署保持单进程。当前登录与后台写操作限流保存在进程内存；切换 PM2 cluster 前，应改为 Redis 共享限流和跨进程 SSE 广播。

## 6. Nginx 反向代理与静态文件

创建 `/etc/nginx/sites-available/fruit-party`：

```nginx
server {
    listen 80;
    server_name <你的域名>;
    root /srv/fruit-party/app/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
        proxy_buffering off;
        proxy_cache off;
    }
}
```

`try_files` 让用户直接访问 `/profile`、`/hub` 等 Vue 路由时仍能加载前端入口。`proxy_buffering off` 让 SSE 通知和维护状态实时到达浏览器。

启用：

```bash
sudo ln -s /etc/nginx/sites-available/fruit-party /etc/nginx/sites-enabled/fruit-party
sudo nginx -t
sudo systemctl reload nginx
```

## 7. HTTPS 与防火墙

确认域名 A 记录已指向服务器公网 IP，再申请证书：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d <你的域名>
sudo certbot renew --dry-run
```

开放 SSH 与 HTTPS，禁止直接对公网开放 Node 和 MySQL：

```bash
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable
sudo ufw status
```

## 8. 每次发布

建议先在后台开启维护，防止新玩家进入发布过程中的新旧版本混合状态。

```bash
cd /srv/fruit-party/app
git pull --ff-only
npm ci
npm test
npm run build
pm2 reload fruit-party-api
curl -fsS http://127.0.0.1:3000/api/health
```

再验证登录、普通关卡开局与结算、无尽模式、后台维护开关、充值确认和通知。

## 9. 备份与回滚

发布前备份数据库：

```bash
mkdir -p /srv/backups/fruit-party
mysqldump -u fruit_app -p --single-transaction --routines --triggers fruit_party \
  | gzip > /srv/backups/fruit-party/fruit_party_$(date +%F_%H%M).sql.gz
```

恢复前先新建测试数据库验证：

```bash
gunzip -c /srv/backups/fruit-party/<备份文件>.sql.gz | mysql -u root -p fruit_party_test
```

代码回滚：

```bash
git log --oneline -10
git checkout <上一个可用提交>
npm ci
npm run build
pm2 reload fruit-party-api
```

数据库结构发生变化时，确认旧版代码兼容当前表结构后再回滚。
