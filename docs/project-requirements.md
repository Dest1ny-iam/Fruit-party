# 水果切切乐需求记录

## 待实现：游戏加载页

加载页不在当前首页阶段实现，等用户明确提出“做加载页”后再开发。

- 普通模式：玩家选择具体关卡后，进入游戏场景前显示加载页。
- 困难模式：玩家选择具体关卡后，进入游戏场景前显示加载页。
- 无尽模式：玩家点击无尽模式入口后，进入游戏场景前显示加载页。
- 加载页采用原创水果主题画面，包含加载进度条和简短提示，不直接使用外部游戏截图或素材。

## 待实现：道具商店与无尽模式复活

- 商店与通知均为顶部导航栏中的图标按钮，不作为首页直接展示的内容模块。
- 点击商店按钮后进入独立商店页面；点击通知按钮后打开独立通知面板。
- 充值按钮暂时为展示入口，点击后提示“未开发”，不接入真实支付功能。
- 玩家可在商店兑换游戏道具。
- 第一种道具为复活卡，仅用于无尽模式。
- 玩家在无尽模式被炸弹击败后，可以消耗一张复活卡继续本局游戏。
- 同一局无尽模式最多复活 3 次。
- 每次复活的复活卡消耗递增；消耗从哪一个数值开始、每次增加多少，在实现商店时再确定。
- 玩家主动退出无尽模式后，本局复活次数和递增消耗重置。
- 第二种道具为分数 1.2 倍卡：启用后，切中水果获得的分数按 1.2 倍计算。
- 分数倍卡的适用模式与持续范围尚未确定，实现商店时再确认。
